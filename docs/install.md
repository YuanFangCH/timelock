# 间隔提醒 0.1.0-preview.4 安装说明

## 获取与校验

从 [0.1.0-preview.4 发布页](https://github.com/YuanFangCH/timelock/releases/tag/v0.1.0-preview.4) 下载 `TimeLock-0.1.0-preview.4.apk` 和 `SHA256SUMS.txt`。在项目本地构建调试版时，APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。校验文件完整性时，将 SHA-256 与下载后的计算值比较：

```powershell
Get-FileHash .\TimeLock-0.1.0-preview.4.apk -Algorithm SHA256
```

## 安装

把 APK 传到手机并打开；系统提示允许当前文件管理器安装未知应用时，按需允许，然后安装并打开“间隔提醒”。本预览包目标 SDK 36，最低系统声明 Android 10 / API 29；目前实测的是 Android 15 / API 35 模拟器。

预览包使用项目独立签名证书。调试构建使用 Android Debug 证书；从调试包切换至预览包时，Android 会因为签名不同而拒绝覆盖安装，需要先卸载调试包。卸载会删除该应用在设备上保存的上次间隔设置。后续预览版本将使用相同预览签名，可直接覆盖更新。

## 首次使用

1. 选择 30 秒、50 秒或 2 分钟，或输入正整数并选“秒/分钟”。允许通知权限，点击“开始提醒”。第一次到达完整间隔后播放一声并继续循环。
2. 试听四种内置声音，或从手机铃声库选择闹钟、通知及其他系统声音。提醒播放遵循系统媒体音量，媒体音量为零时不会播放；使用“调整手机媒体音量”可直接打开系统音量设置。
3. 锁屏前点击“打开电池优化设置”，按系统显示为应用允许后台活动。荣耀 90 具体设置名称依当前 MagicOS 版本而异；未设置时屏幕关闭后提醒可能延迟。
4. 运行时在应用内或通知栏暂停、继续或停止。暂停会保留剩余时间；停止后释放后台计时。

通知被拒绝后仍可从应用页面开始和停止，但通知栏控制可能不可见。媒体音量为零时不会播放；声音跟随系统当前媒体输出。连接蓝牙耳机时，请确认耳机已启用媒体音频并被选为媒体输出。勿扰模式和厂商系统策略可能影响声音表现，真实蓝牙可听性仍待真机验证。

## 卸载或更新

卸载按系统流程操作。调试版只可由同一调试证书覆盖更新；预览版可由后续使用相同预览证书的版本覆盖更新。
