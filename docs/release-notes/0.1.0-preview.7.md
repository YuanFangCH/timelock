# TimeLock 0.1.0-preview.7

**手动组数联动与计时器调整**

## 更新内容

- 加一、减一和归零在关联开启时都会重启当前倒计时并清零累计触发次数。
- 计时暂停时，组数操作会恢复计时并从完整间隔重新开始；计时未开始或已停止时，操作会按当前设置启动计时。
- 关联关闭时，组数操作不会更改计时状态。
- 保留 Android 15 后台提醒服务所需的媒体播放前台服务类型。

## 安装与签名迁移

本版因原预览签名密钥无法恢复而使用新的预览签名证书。Android 不允许用该证书覆盖安装 preview.1 至 preview.6。安装前请卸载旧版本；卸载会清除应用内保存的间隔、声音和组数设置。preview.7 后续版本将沿用本版证书。

## 验证

Android 15 / API 35 AVD 上 Debug 构建、定向计时单元测试通过；验证了空闲加一自动启动、一次触发后减一重启并清零累计，以及暂停后组数操作恢复计时。归零和关闭关联的所有状态组合、锁屏长期运行及荣耀 90 真机体验未覆盖。详细记录见 `test-results/manual-counter-link-20261117/verification.md`。
