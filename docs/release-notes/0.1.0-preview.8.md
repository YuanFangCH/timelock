# TimeLock 0.1.0-preview.8

## 更新内容

- 主界面改为白底配浅蓝色，设置区用细直线分隔，按钮使用细边框和小圆角。
- 倒计时与开始、暂停、继续和停止操作集中在页面顶部。小屏放大字体时，最长倒计时 `24:00:00` 仍可完整显示。
- 新增蓝底白色秒表应用图标。

## 安装

下载 `TimeLock-0.1.0-preview.8.apk` 安装，可直接覆盖 preview.7 并保留设置。从 preview.1 至 preview.6 升级时需先卸载旧版，卸载会清除应用内设置。可用 `SHA256SUMS.txt` 检查 APK 完整性。

Android 15 模拟器已验证主界面、启动图标、计时操作和组数联动。荣耀 90 真机显示待验收。
