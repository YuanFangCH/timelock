# 间隔提醒 0.1.0-preview.1

**首个公开预览版 · 2026-10-24**

从 [GitHub Releases](https://github.com/YuanFangCH/timelock/releases/tag/v0.1.0-preview.1) 获取 `TimeLock-0.1.0-preview.1.apk` 和 `SHA256SUMS.txt`。

## 本版功能

- 快捷设置 30 秒、50 秒或 2 分钟；可输入 1 秒至 24 小时的间隔。
- 到达每个间隔时播放约 0.44 秒的短提示音，然后继续循环。
- 显示倒计时和触发次数；支持试听、暂停、保留剩余时间后继续，以及停止。
- 运行时显示静音通知，支持在通知栏暂停、继续或停止。
- 保存上次设置，无账号、网络、广告或个人数据采集。

## 首发验证

应用和 8 项计时/输入相关单元测试已在 Android 15 / API 35 Pixel 配置模拟器验证。屏幕关闭时，30 秒完成 10 轮，50 秒和 2 分钟各完成 1 轮；三种间隔都有 Android 声音请求接受记录。暂停、继续、停止也已验证。

本次没有连接荣耀 90，未验证受 PIN 保护的锁屏、深度 Doze、长期后台进程回收或实际扬声器的录音/人工听音结果。提示声遵循系统闹钟音量。省电模式或荣耀 MagicOS 后台策略可能延迟提醒；首次使用时查看应用内的电池优化提示并按需允许后台活动。

此预览包使用独立签名证书，后续版本应使用相同签名证书覆盖更新。若要从旧 Android Debug 调试包切换，需要先卸载调试包。源码采用 MIT 许可证。
