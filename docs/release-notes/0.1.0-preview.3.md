# 间隔提醒 0.1.0-preview.3

**提示音音量和选择更新 · 2026-10-24**

从 [GitHub Releases](https://github.com/YuanFangCH/timelock/releases/tag/v0.1.0-preview.3) 获取 APK 和 `SHA256SUMS.txt`。

## 更新内容

- 新增清脆双响、柔和双响、高低提示和三声短响四种原创提示音，可分别试听。
- 可打开 Android 手机系统铃声库，从闹钟、通知、来电等系统声音中选择提示音；应用保存所选声音，重启后继续使用。
- 新增“调整手机闹钟音量”按钮，直接打开系统声音设置。
- 四种内置提示音的 PCM 峰值为满幅的 78%–83%；此前单音为 24%。这项数值描述的是音频波形；手机实际响度取决于设备、声音路由和系统闹钟音量。
- 若所选系统铃声无法访问，会提示用户并改用内置提示音。

## 本轮验证

Android 15 / API 35 模拟器已验证四种内置 WAV 的峰值和 RMS、试听两种内置声音、打开系统铃声库并选择 “Cosmic Play”、强停应用后保留所选铃声、从系统声音设置返回，以及屏幕关闭时按 30 秒间隔播放所选系统铃声。系统铃声在模拟器按时触发并于约 2.5 秒后停止。

尚未在荣耀 90 扬声器上录音或人工听音。系统声音遵循闹钟音量，音量为零、静音、勿扰、蓝牙路由以及荣耀 MagicOS 可能影响听感或投递表现；请在荣耀 90 上试听并调整“闹钟音量”。
