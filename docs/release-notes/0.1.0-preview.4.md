# 间隔提醒 0.1.0-preview.4

**媒体输出通道修复 · 2026-10-29**

从 [GitHub Releases](https://github.com/YuanFangCH/timelock/releases/tag/v0.1.0-preview.4) 获取 `TimeLock-0.1.0-preview.4.apk` 和 `SHA256SUMS.txt`。

## 更新内容

- 内置提示音、手机系统铃声及试听统一改用媒体通道，声音跟随系统当前媒体输出，连接蓝牙耳机时遵循系统的媒体输出选择。
- 音量检查、页面提示和应用内音量键同步使用媒体音量；媒体音量为零时跳过声音并显示提示，闹钟音量不再控制提醒声。
- 延续上一预览版签名，可覆盖安装 preview.3，保留原设置。

## 验证与限制

Android 15 / API 35 独立模拟器已通过四种内置音与系统铃声 Drip 的试听、定时提醒和停止，确认 SoundPool 与实际系统铃声 MediaPlayer 使用媒体属性；媒体音量为零时拒绝播放，闹钟被系统策略静音且媒体未静音时正常接受播放。息屏循环、恢复页面、暂停、继续和选项保存均通过。详细结果见仓库 `test-results/bluetooth-media-20261029/verification.md`。

该模拟器闹钟音量最低为 1，因此闹钟静音使用“禁止闹钟、允许媒体”的系统策略验证。音量键的目标流已确认是媒体，模拟器注入按键的实际音量增量未验证。

模拟器结果不代表真实蓝牙耳机可听性。真实耳机、播放中连接/断开耳机、荣耀 MagicOS 后台策略、深度 Doze、受 PIN 保护锁屏和耗电仍待真机验收。使用前请确认媒体音量非零，并在系统中选择期望的媒体输出设备。
